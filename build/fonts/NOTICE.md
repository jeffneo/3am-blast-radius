# Lab Mono

`LabMono-Regular.ttf` is a modified version of **Source Code Pro Regular** (version 2.038), used only to typeset the monospaced text in the PDFs. The one change: the underscore is raised 100 units so it stays on its line when text is copied out of a PDF on macOS (see `make_labmono.py`).
